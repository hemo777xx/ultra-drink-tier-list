🍺 Drink Tier List
Веб-приложение для создания тир-листов напитков с загрузкой фото и синхронизацией через Netlify Blob Storage.

Функционал
Загрузка фото (JPG, PNG, WebP) до 5 МБ
Автоматическое сжатие и конвертация в WebP на клиенте
5 уровней тир-листа (S, A, B, C, D)
Drag & Drop для ПК, Long-Press для мобильных
Экспорт результата в PNG
Темная/Светлая темы
Офлайн режим (PWA)
